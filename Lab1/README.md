# Lab 1: Introduction to AI & Paradigms (CS4944 / CA1601400)

## Description
Compares symbolic (rule-based) and probabilistic (threshold-based) decision-making on a synthetic scholarship screening scenario, evaluates boundary conditions, and extends the rule-based engine with two explicit named conditions (`gpa >= 3.0` and `attendance_rate >= 80`).

## Included Files
- `lab1_compare.py` — Guided comparison between the symbolic rule checker and probability threshold rule, including boundary isolation tests (`69` vs. `0.69`).
- `lab1_rules.py` — Extended rule-based scholarship screening system with four explicit conditions, four core test cases, and an incomplete-document edge case.
- `Lab1_Report.docx` — Lab 1 academic report containing the sourced historical timeline, rule test results, disagreement analysis, and conversational-test critique.
- `output.txt` — Captured console output from executing `lab1_compare.py` and `lab1_rules.py`.

## Requirements
- Python 3.8+ (standard library only).

## Execution Commands
```bash
python lab1_compare.py
python lab1_rules.py
```
